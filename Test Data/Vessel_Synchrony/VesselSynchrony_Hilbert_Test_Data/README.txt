Vessel Synchrony Hilbert - Test Data

test_01_high_synchrony.csv
Three vessel ROIs with nearly identical 0.10 Hz phases.

test_02_known_phase_offsets.csv
Three 0.10 Hz vessel ROIs with approximately 0, 90, and 180 degree phase positions.

test_03_consistent_time_delay.csv
Three 0.10 Hz vessel ROIs with approximately 0, 1, and 2 second delays.

test_04_low_phase_locking.csv
Three vessel ROIs whose relative phases drift over time, providing a lower-PLV test.

test_05_four_rois.csv
Four vessel ROIs with several fixed phase offsets to exercise all pairwise comparisons and matrices.

Format
Frames are in column D, Time in E, and vessel ROI diameter signals begin in column F. Numeric data begin on row 12. Vessel diameter is percent of baseline 100.
